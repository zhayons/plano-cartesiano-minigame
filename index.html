🖨️ Impressora 3D: Missão Coordenadas

Dois motores, uma missão! Jogador 1 controla o Motor X, Jogador 2 controla o Motor Y. Trabalhem em equipe para levar o bico até cada quadradinho do desenho e apertar ENTER para depositar o filamento.

Posição do Bico

🔵 Motor X — Jogador 1

A / ← mover para a esquerda

D / → mover para a direita

🟣 Motor Y — Jogador 2

O / ↑ mover para cima

L / ↓ mover para baixo

🟠 Extrusora

ENTER ou ESPAÇO deposita ou apaga o filamento
